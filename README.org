** clojure-lsp

   Installed with script in /usr/local/bin,
   https://emacs-lsp.github.io/lsp-mode/tutorials/clojure-guide/  (Eric Dallo)

   Official guide, but with tweaks:

   What I kept:
   + Performance tuning (gc-cons-threshold, read-process-output-max)
   + Hooks for clojure-mode, clojurescript-mode, clojurec-mode
   + LSP as the intelligence layer

   What I have changed or removed:
   + company-mode (for now)
   + LSP provides completion via completion-at-point
   + Works with our existing Vertico/Orderless stack
   + Simpler, fewer moving parts
   + Removed flycheck - LSP has built-in diagnostics.

   Characteristics (observed so far):
   + lsp-mode shows errors/warnings automatically
   + No need for separate checker
   + Removed lsp-treemacs

   Usage (so far):
   + Jump to definition - M-. (lsp-ui-peek)
   + Find references - M-?
   + Completion - Works with TAB/completion-at-point
   + Rename - C-c l r
   + Code actions - C-c l a
   + Hover documentation - Automatic in minibuffer
   + Diagnostics - Errors/warnings inline
   + Compliant with Cider
   + Paredit and structural editing untouched

** corfu / cape

   In-buffer completion UI, the companion to Vertico for
   =completion-at-point=. Corfu renders the popup; Cape supplies extra
   backends (file paths, dabbrev, etc.).

   Configured in 'settings/setup-corfu.el'.

*** Why Corfu, not Company:
   + CAPF-native, same minimalist philosophy as Vertico/Orderless
   + Works automatically with LSP, Cider and Sly - no per-mode backends
   + Fewer moving parts, lighter than company-mode

*** Behaviour:
   + Popup appears automatically while typing (corfu-auto)
   + corfu-popupinfo shows docs for the selected candidate

| Key     | Description                                  |
|---------+----------------------------------------------|
| =TAB=   | Complete / cycle candidates                  |
| =C-n=   | Next candidate                               |
| =C-p=   | Previous candidate                           |
| =RET=   | Accept selected candidate                    |
| =C-g=   | Abort completion                             |
| =M-d=   | Toggle documentation popup (corfu-popupinfo) |
| =C-M-i= | Manually trigger completion-at-point         |

** sly

   Common Lisp IDE, the SBCL counterpart to Cider. Configured in
   'settings/setup-sly.el'.

*** Setup notes:
   + SBCL installed system-wide via =apt install sbcl= (=/usr/bin/sbcl=)
   + =inferior-lisp-program= set to "sbcl"
   + Completion via completion-at-point - works with Corfu, no extra wiring
   + Contribs: sly-quicklisp, sly-asdf (loaded if present)

*** Quicklisp:
   + Installed per-user in =~/quicklisp/= (NOT system-wide / not under sudo)
   + Loaded at SBCL startup via =~/.sbclrc= (written by =ql:add-to-init-file=)
   + Because Sly launches sbcl as your user, it reads your ~/.sbclrc and
     Quicklisp is available automatically in the REPL

*** NOTE to self:
   + Files in $HOME must be owned by your dev user, not root. A missing or
     root-owned ~/.sbclrc is the usual cause of the slynk-quicklisp
     MISSING-DEPENDENCY error at connect time.

* Using Emacs
** General

| Key       | Description                                  |
|-----------+----------------------------------------------|
| ~C-x u~   | Undo tree                                    |
| ~C-k~     | Kill to end of form (structurally safe)      |
| ~M-k~     | Kill whole form                              |
| ~C-M-k~   | Kill forward expression                      |
| ~C-x C-f~ | Open a file. Starts in the current directory |

** Hippie-expand basics

   Usage patterns:

| ~M-/~     | Smart expansion with all strategies                       |
| ~C-M-/~   | Expand full lines only (great for repeating similar code) |
| ~C-c /~   | Case-sensitive expansion                                  |
| ~C-c M-/~ | Words/symbols only (no file paths or lines)               |
| ~C-c C-/~ | Current buffer only (faster, less noise)                  |
| ~C-c f /~ | File name completion only                                 |

** Paredit

   Paredit operations are semantic:

| Key       | Description          |
|-----------+----------------------|
| ~C-→~     | slurp (expand form)  |
| ~C-←~     | barf (contract form) |
| ~M-s~     | splice (unwrap)      |
| ~M-(~     | wrap                 |
| ~C-M-f/b~ | navigate by form     |

** Navigation:

| Key         | Description                   |
|-------------+-------------------------------|
| ~C-M-f~     | Forward by expression         |
| ~C-M-b~     | Backward by expression        |
| ~C-M-u~     | Up in tree                    |
| ~C-M-d~     | Down in tree                  |
| ~C-→~       | Slurp right (pull into form)  |
| ~C-<right>~ | Slurp right (pull into form)  |
| ~C-←~       | Barf right (push out of form) |
| ~C-<left>~  | Barf right (push out of form) |
| ~C-M-←~     | Slurp left                    |
| ~C-M-→~     | Barf left                     |

** Wrapping:

| Key               | Description              |
|-------------------+--------------------------|
| ~M-(~             | Wrap with ()             |
| ~M-s~             | Splice (remove wrapping) |
| ~M-S (shift-s)~   | Split expression         |
| ~M-J~             | Join expressions         |

** Consult

| Key     | Description                                                                  |
|---------+------------------------------------------------------------------------------|
| ~C-x b~ | consult-buffer    - Buffer switching with groups (files, buffers, bookmarks) |
| ~M-s l~ | consult-line      - Jump to any line in current buffer                       |
| ~M-g g~ | consult-goto-line - Better goto-line with preview                            |
| ~M-g i~ | consult-imenu     - Navigate code structure (great for Clojure!)             |

** Sly (Common Lisp REPL)

   Start with =M-x sly= (launches sbcl and connects to a *sly-mrepl*).

| Key         | Description                          |
|-------------+--------------------------------------|
| =M-x sly=   | Start / connect REPL                  |
| =C-c C-c=   | Compile current top-level form        |
| =C-c C-k=   | Compile & load whole file             |
| =C-x C-e=   | Eval form before point                |
| =C-c C-z=   | Switch to REPL                        |
| =M-.=       | Jump to definition                    |
| =M-,=       | Jump back                             |
| =C-c C-d d= | Describe symbol                       |
| =C-c C-d h= | HyperSpec lookup                      |

*** Sly REPL history

    SLY history is bound to M-p/M-n by default; CIDER-style arrow
    bindings are added in setup-sly.el.

| Key       | Description                              |
|-----------+------------------------------------------|
| =M-p=     | Previous input                           |
| =M-n=     | Next input                               |
| =M-r=     | Search history backwards (incremental)   |
| =M-s=     | Search history forwards                  |
| =C-<up>=  | Previous input (CIDER-style, custom)     |
| =C-<down>=| Next input (CIDER-style, custom)         |

    Note: history is persistent across sessions.
