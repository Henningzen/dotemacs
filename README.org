** corfu / cape
In-buffer completion UI, the companion to Vertico for =completion-at-point=.
Corfu take care of rendering the popup, while Cape supplies extra backends
(file paths, dabbrev, etc.).

Configured in 'settings/setup-corfu.el'.

*** Why Corfu, not Company:
+ CAPF-native (completion-at-point-functions) same minimalist philosophy
  as Vertico and Orderless
+ Works automatically with Cider and Sly - no config per backend
+ Less complexity from fewer moving parts, and lighter than company-mode

*** Behaviour:
+ Popups will appear automatically while typing (corfu-auto)
+ corfu-popupinfo shows docs for the selected candidate

| Key     | Description                                  |
|---------+----------------------------------------------|
| =TAB=   | Complete / cycle candidates                  |
| =C-n=   | Next candidate                               |
| =C-p=   | Previous candidate                           |
| =RET=   | Accept selected candidate                    |
| =C-g=   | Abort completion                             |
| =M-d=   | Toggle documentation popup (corfu-popupinfo) |
| =C-M-i= | Manually trigger completion-at-point         |

What I have changed or removed:

+ LSP provides completion via completion-at-point

+ Less complexity while LSP is driving, it simpler, fewer moving parts involved.
+ Removed flycheck - LSP has built-in diagnostics.

Characteristics (observed so far):
+ lsp-mode shows errors/warnings automatically
+ No need for separate checker
+ (Removed lsp-treemacs)

Usage (what I learned so far):

+ Find references - M-?

+ Rename - C-c l r
+ Code actions - C-c l a
+ Hover documentation - Automatic in minibuffer
+ Diagnostics - Errors/warnings inline
+ Compliant with Cider
+ Paredit and structural editing untouched

** sly
Common Lisp IDE, the SBCL counterpart to Cider. Configured in
'settings/setup-sly.el'.

*** Setup notes:
+ SBCL installed system-wide via =apt install sbcl= (=/usr/bin/sbcl=)
+ =inferior-lisp-program= set to "sbcl"
+ Completion via completion-at-point - works with Corfu, no extra wiring
+ Contribs: sly-quicklisp, sly-asdf (loaded if present)

*** Quicklisp:
+ Installed per-user in =~/quicklisp/= (NOT system-wide / not under sudo)
+ Loaded at SBCL startup via =~/.sbclrc= (written by =ql:add-to-init-file=)
+ Because Sly launches sbcl as your user, it reads your ~/.sbclrc and
  Quicklisp is available automatically in the REPL

*** NOTE to self:
+ Files in $HOME must be owned by your dev user, not root. A missing or
  root-owned ~/.sbclrc is the usual cause of the slynk-quicklisp
  MISSING-DEPENDENCY error at connect time.

** Completion
Two complementary strategies for text completion:

*** Primary: Corfu (automatic popup)
Default completion UI that pops up while you type. Works with Cider, Sly, and
file paths via Cape. This is the best choice for typical completion scenarios.

| Key     | Description                                  |
|---------+----------------------------------------------|
| =TAB=   | Complete / cycle candidates                  |
| =C-n=   | Next candidate                               |
| =C-p=   | Previous candidate                           |
| =RET=   | Accept selected candidate                    |
| =C-g=   | Abort completion                             |
| =M-d=   | Toggle documentation popup (corfu-popupinfo) |
| =C-M-i= | Manually trigger completion-at-point         |


*** Supplementary: Hippie-expand (manual expansion)
Triggered manually with ~M-/~. Cycles through various expansion strategies
(dabbrev, file names, lines, symbols). Gives me an option for different
expansion styles or if I need more control.

| ~M-/~     | Smart expansion with all strategies                       |
| ~C-M-/~   | Expand full lines only (great for repeating similar code) |
| ~C-c /~   | Case-sensitive expansion                                  |
| ~C-c M-/~ | Words/symbols only (no file paths or lines)               |
| ~C-c C-/~ | Current buffer only (faster, less noise)                  |
| ~C-c f /~ | File name completion only                                 |

*** Sly REPL history
SLY history is bound to M-p/M-n by default; CIDER-style arrow bindings are added
in setup-sly.el.

| Key       | Description                              |
|-----------+------------------------------------------|
| =M-p=     | Previous input                           |
| =M-n=     | Next input                               |
| =M-r=     | Search history backwards (incremental)   |
| =M-s=     | Search history forwards                  |
| =C-<up>=  | Previous input (CIDER-style, custom)     |
| =C-<down>=| Next input (CIDER-style, custom)         |

*Note: history is persistent across sessions.*
